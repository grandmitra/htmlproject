      • Penurunan % Value di Akhir Tahun: % Value bulanan bergerak dari 24,59% (Januari) dan memuncak di 25,53% (Mei), lalu menyusut menjadi 8,36% pada November seiring kenaikan Balance Value ke titik tertinggi bulanan.

      • Balance Melebihi INVENT (Selisih Negatif): Pada PAINT & SUNDRIES (rata-rata Selisih Value -Rp 414.655.663,04; % Value -38,68%) dan FLOORING & WALL (-Rp 161.712.641,25; % Value -15,14%), rata-rata Balance Value lebih tinggi daripada rata-rata INVENT.
      • Pertumbuhan Kategori Unggulan: BUILDING MATERIAL mencatat kenaikan Balance Value tertinggi dari Januari ke November (+63,20%), diikuti PAINT & SUNDRIES (+25,39%) dan PLUMBING (+22,70%).
