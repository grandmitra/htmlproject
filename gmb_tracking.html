Panduan Koneksi Google Apps Script

1. Buka Google Spreadsheet Anda (Link Spreadsheet).

2. Klik menu Extensions (Ekstensi) > Apps Script.

3. Hapus semua kode default, paste kode backend di bawah ini:

4. Klik tombol Deploy > New Deployment.

5. Pilih jenis Web app, ganti akses ke Anyone (Siapa Saja), lalu klik Deploy.

6. Copy Web App URL dan paste pada kolom input "Google Apps Script Web App URL" di atas aplikasi ini.
